# АС «Учёт инструментов»

Курсовая работа по дисциплине «Проектирование и архитектура программных систем», вариант № 2.

Веб-приложение: сервер на Node.js, база данных SQLite (встроенный модуль `node:sqlite`), клиент на HTML/CSS/JavaScript. Внешних зависимостей нет.

## Запуск

Требуется Node.js 22.5 или новее.

```
node server.js
```

Откройте http://localhost:3000. При первом запуске создаётся `data/tools.db` с демонстрационными данными.

Переменные окружения: `PORT` (по умолчанию 3000), `DB_PATH` (по умолчанию `data/tools.db`).

## Тесты

```
npm test
```
