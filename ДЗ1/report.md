# ДЗ 1. Сравнительный анализ и настройка AI-инструментов

## 1. Задача и требования
**Задача:** разработать приложение «ЕдаНаНеделю» (заказ готовых наборов здорового питания): мобильный клиент, backend, база данных, ТЗ и тесты. Это та же идея, что в ДЗ 3, и проект будет развиваться в ДЗ 4–6.

| Требование | Значение | Что это значит для выбора |
|---|---|---|
| Сложность | Много связанных файлов: ТЗ, фронтенд, бэкенд, миграции, тесты | Нужен доступ ко всему проекту и многошаговая работа |
| Доступ к локальным файлам | Обязателен: ТЗ и код лежат на диске, нужен запуск тестов | Облачные «чат-генераторы» подходят хуже |
| Безопасность данных | В проекте будут номера телефонов и адреса (152-ФЗ) | Предпочтителен локальный проект, секреты вне кода |
| Бюджет | Ограничен, студенческий | Один инструмент вместо нескольких подписок |
| Процесс | Правила проекта (ДЗ 2), документы Markdown, тесты (ДЗ 4) | Нужны файл правил проекта и запуск команд |

Отсюда веса критериев в таблице: контекст ×3, качество ×2, безопасность ×2, интеграция ×2, скорость ×1, стоимость ×1.

## 2. Анализ инструментов
Полная таблица оценок — в `comparison_table.md` (4 класса ожидания выполнены: 3 облачных и 4 IDE/CLI).

**Различие классов:**
- **Cloud-агенты** (Bolt.new, Lovable, Replit Agent): работают в браузере, проект и запуск в облаке сервиса. Сильны в быстром прототипе, слабее при работе с большим существующим проектом и собственными правилами.
- **IDE-агенты** (Cursor, GitHub Copilot): встроены в редактор, видят открытый проект, предлагают правки в интерфейсе IDE.
- **CLI-агенты** (Claude Code, Gemini CLI): работают в терминале, сами читают и меняют файлы и запускают команды.

Итоги взвешенной оценки (максимум 55): Cursor 46, Claude Code 45, GitHub Copilot 39, Gemini CLI 38, Replit Agent 32, Lovable 30, Bolt.new 28.

Оценки субъективные, и реально проверен только Claude Code (см. предупреждение в таблице).

## 6. Выводы и рекомендации
- Для сквозного проекта с локальными файлами, документами и тестами подходит агент IDE/CLI-класса; облачные генераторы удобнее для быстрых прототипов интерфейса.
- Лидеры по моей оценке (Cursor и Claude Code) не различимы по баллам, что нужно проверить опытом: стоит выполнить одну и ту же задачу в обоих и сравнить число итераций и качество.
- Не вставлять в промпты реальные номера телефонов и адреса, секреты хранить вне кода.
- Тарифы и возможности инструментов быстро меняются; перед платной подпиской нужно сверить актуальные условия на сайтах.
